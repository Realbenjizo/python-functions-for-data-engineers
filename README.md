# Python Functions for Data Engineers
Supporting code examples, Jupyter notebooks, and datasets for the book
**Python Functions for Data Engineers: Write Cleaner, Faster, Safer
Pipelines** by Benjamin Bennett Alexander.

This repository accompanies the book and provides practical examples of
how to apply software engineering principles when building Python data
pipelines.

The goal is not simply to write Python code that works. It is to write
code that is readable, reusable, testable, maintainable, and reliable.
What You'll Find Here
The repository contains the supporting materials used throughout the
book:
- Jupyter notebooks: Practical code examples that demonstrate the
  concepts covered in each chapter.
- Datasets: Sample CSV files and other data used in the exercises.
- Code examples: Python implementations of the techniques
  discussed in the book.
- Exercises: Opportunities to experiment with the concepts and
  adapt the examples.
The materials are organized by chapter so you can follow along as you
read.
Getting Started
You can work with the examples using Google Colab, Jupyter Notebook,
Visual Studio Code, or another Python development environment.

You do not need to use a particular IDE or development platform. Choose
the environment you are most comfortable with.
1. Get the Repository
Clone the repository:
git clone https://github.com/Realbenjizo/python-functions-for-data-engineers.git
Alternatively, select Code → Download ZIP on GitHub and extract the
files to your computer.

2. Set Up Python
Make sure you have Python installed. Python 3.10 or later is a
provisional recommendation; check the requirements for the examples
before choosing your version.

If you are using Google Colab, you can install the required packages
directly in a notebook. For example:

%pip install pandas requests pandera

Some chapters may require additional libraries. Follow the installation
instructions provided in the relevant notebook.
